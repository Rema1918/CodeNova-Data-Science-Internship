# CodeNova Data Science Internship

## Project Overview
This repository contains data science projects completed as part of the CodeNova Data Science Internship.

## Task 1: Sales Data Analysis
- Analyzed online retail sales data using Python and Pandas.
- Calculated revenue, order count, and quantity sold.
- Analyzed monthly sales trends and top-selling products.
- Created charts to understand sales performance.

## Task 2: Data Cleaning
- Identified missing values and duplicate records.
- Removed duplicate rows and invalid transactions.
- Created a cleaned dataset and data cleaning report.

## Task 3: Interactive Sales Dashboard
- Developed an interactive dashboard using Streamlit.
- Displayed sales revenue, order count, quantity sold, monthly trends, and top products.

## Task 4: Customer Segmentation
- Used the K-Means clustering algorithm.
- Grouped customers based on their orders, quantity purchased, and spending.
- Created customer segment summaries and visualizations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit
- Google Colab
- GitHub

## Dataset
Online Retail dataset from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/352/online+retail

## Conclusion
These projects demonstrate data cleaning, sales analysis, dashboard development, and customer segmentation using Python.
